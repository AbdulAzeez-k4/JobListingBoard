# 🧑‍💼 Job Listing Board (React)

A simple React app to browse job listings with search and filter functionality.

## ✨ Features
- 🔍 Search by job title
- 🧾 Filter by job type (Full-Time, Part-Time, Contract)
- 📦 Mock data (can be replaced with real API)

## 🛠 Tech Stack
- React.js
- HTML/CSS (no frameworks)
- useState, useEffect

## 🧪 Local Setup
```bash
git clone https://github.com/your-username/job-listing-board.git
cd job-listing-board
npm install
npm start
